| Problema/Oportunidad<br>La sala médica gestiona sus turnos, disponibilidad de profesionales, stock de vacunas y cobros de manera ineficiente y desconectada. Existe la oportunidad de centralizar y digitalizar todos estos procesos, lo que permitirá optimizar el tiempo del personal, un manejo eficiente del stock y ofrecer a los pacientes una experiencia de autogestión mucho más ágil. |  |  |  |
| Meta<br>Desarrollar e implementar un sistema integral web y una aplicación móvil que centralizan la gestión de la agenda médica, historial clínico, control de vacunas y pagos, mejorando la organización interna y la agilidad de atención. |  |  |  |
| Objetivos<br>- Implementar el módulo de agenda médica antes del 11/10/2026, permitiendo que el 100% de los médicos registre digitalmente sus horarios de atención y que los pacientes puedan reservar turnos según la disponibilidad registrada.<br>- Implementar el módulo de pagos y facturación antes del 15/11/2026, permitiendo procesar el 100% de las consultas particulares mediante una pasarela de pago y generar comprobantes digitales.<br>- Implementar el módulo de gestión de vacunas antes del 25/10/2026, permitiendo registrar y actualizar el stock y generar alertas automáticas para el 100% de los casos en que el stock alcance el nivel mínimo establecido.<br>- Implementar el módulo de historia clínica antes del 11/10/2026, permitiendo que el 100% de los médicos registre diagnósticos y tratamientos y que los pacientes puedan consultar su historial desde la plataforma.<br>- Implementar un módulo de reportes que permita a los administradores consultar información sobre turnos, stock de vacunas, pagos realizados y asistencia de pacientes para el 25/10/2026, cubriendo el 100% de los tipos de reporte definidos .<br>- Desarrollar y desplegar la aplicación móvil para pacientes para el 15/11/2026, permitiendo reservar turnos, consultar el historial clínico, recibir recordatorios y gestionar pagos. |  |  |  |
| Criterios de éxito<br>- Reducción a 0 de los casos de doble reserva de un mismo turno.<br>- Reducción a 0 de los casos de vacunación sin stock disponible verificado.<br>- [60]% de los turnos reservados por autogestión a los 3 meses de puesta en marcha el sistema.<br>- La satisfacción de pacientes y médicos es igual o mayor a 8/10 en encuesta post implementación.<br>- El equipo implementador entrega las funcionalidades priorizadas de cada sprint sin retrasos que comprometan<br>la fecha de cierre del proyecto.<br>Nivel de |  |  |  |
