## Criterios de conversión

- Los 12 archivos originales se conservan sin cambios. Las versiones Markdown agregan `.md` al nombre completo para distinguir fuentes con el mismo nombre, como `.docx` y `.pdf`.
- Word: contenido textual, listas y tablas; las imágenes se conservan en carpetas `.assets` cuando existen.
- PDF: texto separado por página; la maquetación puede variar. WBS y camino crítico incluyen imágenes de las páginas para conservar gráficos y colores.
- DER: entidades, claves y relaciones transcritas desde el XML de `.drawio`; la imagen PNG queda enlazada.
- ProjectLibre: extracción parcial de cadenas legibles del `.pod`, expresamente señalada. Para fechas, dependencias y cálculos debe consultarse el original.
- Los originales son la referencia cuando haya diferencias de formato o contenido visual.
